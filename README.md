# ZHENG RONGWEI — Personal AI Portfolio

Static, responsive, bilingual GitHub Pages portfolio. No build tool required.

## Preview
Open `index.html` in a browser. Google Fonts uses the network, but system fonts are provided as fallback.

## Publish at `https://zhengrongwei.github.io/`
GitHub requires the repository **owner** to be named `zhengrongwei`. Create a GitHub organization named `zhengrongwei` (if available) and a **public** repository named `zhengrongwei.github.io` under that organization, then upload these files to its root. Go to Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

An alternative is changing the GitHub user account to `zhengrongwei`, but this can affect integrations and is not necessary.

- Style / effects: `style.css`
